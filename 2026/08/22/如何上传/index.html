零基础教程：如何将本地文件与项目上传至GitHub

Created2026-08-22|Updated2026-08-22|教程
|Post Views:

本文适合GitHub新手，提供网页上传、Git命令行、图形工具三种上传方案，一步步带你完成项目上传。

一、前期准备工作

  1. 注册并登录 GitHub
  2. 创建全新仓库
    • 点击网页右上角 + → New repository
    • 填写仓库名称
    • ✅新手建议：不要勾选 Add a README file，避免推送代码时出现冲突报错
    • 仓库权限选择 Public(公开) 或者 Private(私有)
    • 点击 Create repository 创建仓库
  3. 创建完成后，复制仓库的HTTPS链接，后续命令需要用到。

方案一：网页拖拽上传（少量文件首选，无需安装软件）

⚠️限制：单个文件最大25MB，不支持完整多级文件夹上传

  1. 打开你的GitHub仓库主页
  2. 点击 Add file → Upload files
  3. 将电脑本地文件直接拖拽到虚线上传区域，也可以点击choose your files手动选择文件
  4. 页面下方填写提交说明（Commit message），例：上传PDF学习资料
  5. 保持默认选项 Commit directly to the main branch
  6. 点击 Commit changes，上传完毕，刷新网页即可查看文件。

方案二：Git命令行上传（推荐，适合完整项目、大量文件）

1、安装Git工具

下载地址：https://git‑scm.com/
安装全程选择默认配置即可。

2、第一次上传全新项目

  1. 在电脑建立本地项目文件夹，把所有待上传的文件放入文件夹内
  2. 在文件夹空白位置右键 → Git Bash Here，打开命令终端
  3. 逐条执行下方命令，每输入一行按下回车
#初始化本地仓库
git init
#将文件夹内全部文件加入暂存区
git add .
#提交文件，引号内填写本次上传备注
git commit -m "第一次上传我的项目文件"
#关联远程GitHub仓库，替换为你自己仓库的HTTPS地址
git remote add origin https://github.com/360is/-.git
#设置主分支名称为main
git branch -M main
#推送文件上传到GitHub
git push -u origin main
